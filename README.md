# Shayaan Nakhwa — Portfolio

A monochrome React + Vite portfolio with Motion transitions, a liquid-glass navbar, and the official React Bits ProfileCard, GradualBlur, VariableProximity, ScrollReveal, PatternWaves, and AnimatedList components.

Run with `npm install` and `npm run dev`. Build with `npm run build`.

The portrait is imported from `image.png`. Edit content in `src/main.jsx` and styles in `src/style.css`. The resume is in `public/Shayaan_Nakhwa_Resume.pdf`.
